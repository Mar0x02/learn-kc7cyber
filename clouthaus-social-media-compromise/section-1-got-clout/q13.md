# Q13

**Pertanyaan:** What username did she enter?

**Konteks:**
Fake login page (clone dari trusted login page Dior) kelihatan clean banget, Afomiya gak mikir dua kali dan langsung ketik credentials-nya. Ini classic phishing tactic: clone login page buat manen credentials.

**Cara penyelesaian:** Lihat screenshot fake login page, baca username yang diketik Afomiya.
