# Q14

**Pertanyaan:** What is the IP address associated with the domain?

**Konteks:**
Cari tau di mana domain mencurigakan `super-brand-offer.com` ([Q11](./q11.md)) ini sebenernya "tinggal", dan apakah dia juga hosting aktivitas jahat lain.

**Cara penyelesaian:**
```kql
PassiveDns
| where domain contains "super-brand-offer.com"
```
