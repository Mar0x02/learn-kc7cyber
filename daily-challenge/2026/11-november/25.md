# Daily Challenge - 2026-11-25

**Pertanyaan:** What Linux kernel mechanism isolates process views of resources such as process IDs, mount points, and network stacks?

**Jawaban:** Namespaces

**Penjelasan singkat:**
Normalnya, semua process di satu mesin "berbagi" satu pandangan yang sama atas resource sistem — satu daftar PID yang sama, satu filesystem yang sama, satu network stack yang sama. Tapi kadang kita mau isolasi: misal container A gak boleh liat process container B, atau gak boleh liat filesystem host.

Di sinilah **namespaces** main perannya — mekanisme kernel yang bikin tiap proses/grup proses punya "pandangan" sendiri atas resource sistem, seolah-olah terisolasi dari proses lain, padahal sebenernya masih jalan di kernel fisik yang sama. Beberapa tipe yang relevan: PID namespace (proses ID sendiri — bisa aja PID 1 di dalam container padahal di host PID-nya beda), mount namespace (filesystem view sendiri), network namespace (network stack sendiri, termasuk IP dan port-nya sendiri).

Ini fondasi yang dipakai container (Docker, dkk) buat bikin tiap container berasa kayak mesin terpisah, padahal cuma proses biasa yang "dikasih kacamata" beda sama kernel yang sama.
