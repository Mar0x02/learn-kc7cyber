# Daily Challenge - 2026-11-28

**Pertanyaan:** What Linux capability permits binding to privileged Internet ports below 1024 when the privileged-port threshold has its default value?

**Jawaban:** `CAP_NET_BIND_SERVICE`

**Penjelasan singkat:**
Linux punya sebuah sistem namanya **capabilities**, fungsinya buat memecah akses-akses yang awalnya cuma bisa dilakukan sama user root jadi izin-izin kecil yang lebih spesifik.

Kenapa ini penting? Contohnya web server kayak Apache atau Nginx — biar bisa bind ke port 80, awalnya dia *harus* punya akses root. Ini bahaya banget, karena kalau ada vuln di service web server itu, attacker yang exploit bisa langsung dapet akses root ke seluruh sistem.

Nah, salah satu capability yang ada buat ngatasin ini adalah `CAP_NET_BIND_SERVICE` — capability yang khusus ngasih izin buat bind ke port privileged (0-1023) tanpa perlu jadi root penuh. Jadi web server bisa tetep listen di port 80 tapi jalan sebagai user biasa, lebih aman kalau suatu saat ke-exploit.

Threshold "privileged port"-nya (default 1024) diatur di `/proc/sys/net/ipv4/ip_unprivileged_port_start`.
