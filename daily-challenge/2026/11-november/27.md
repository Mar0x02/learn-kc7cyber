# Daily Challenge - 2026-11-27

**Pertanyaan:** What field in /proc/<pid>/status lists a thread's IDs across nested PID namespaces, starting with the namespace of the procfs mount?

**Jawaban:** `NSpid`

**Penjelasan singkat:**
Bukan `NStgid` ya — itu field beda (Thread **Group** ID/PID proses, bukan thread ID individual). `NSpid` nunjukin Thread ID task itu di tiap layer PID namespace yang nested, urutan mulai dari namespace tempat procfs di-mount, lanjut ke namespace yang lebih dalam.
