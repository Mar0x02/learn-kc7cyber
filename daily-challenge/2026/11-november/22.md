# Daily Challenge - 2026-11-22

**Pertanyaan:** What restricted-access file conventionally stores local users' password hashes and password-aging information?

**Jawaban:** `/etc/shadow`

**Penjelasan singkat:**
Jaman dulu, password hash user itu disimpen langsung di `/etc/passwd` — tapi file ini harus readable semua orang (soalnya banyak tool butuh baca UID/GID/home dir/shell dari situ). Masalahnya, kalau hash password ikut nimbrung di file yang bisa dibaca semua orang, attacker gampang nyolong hash-nya terus di-brute-force offline.

Makanya hash password-nya dipindahin ke file terpisah yang dibatesin aksesnya: `/etc/shadow`. File ini nyimpen password hash tiap user lokal (bukan plaintext) plus info password-aging (kapan terakhir ganti, umur minimal/maksimal sebelum wajib ganti, masa tenggang sebelum akun dikunci, dll). Permission-nya biasanya `600`/`640` dengan owner root, jadi cuma root (atau proses dengan privilege setuid kayak `passwd`) yang bisa baca.
