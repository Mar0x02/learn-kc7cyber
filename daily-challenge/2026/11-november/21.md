# Daily Challenge - 2026-11-21

**Pertanyaan:** What configuration file conventionally defines filesystems to mount at boot and their mount options?

**Jawaban:** `/etc/fstab`

**Penjelasan singkat:**
Pas Linux boot, sistem perlu tau filesystem apa aja yang harus di-mount dan ke mana (misal partisi root, `/home`, `/boot`, dll) — daripada di-setting manual tiap nyala, semua itu didaftarin di satu file konfigurasi: `/etc/fstab`.

Tiap baris di file ini isinya 6 kolom: device/UUID, mount point, filesystem type, mount options (termasuk opsi kayak `nosuid` yang kita bahas di soal sebelumnya), dump flag, dan fsck order. Jadi selain otomatis ke-mount pas boot, file ini juga yang dibaca kalau kita jalanin `mount -a` (mount ulang semua entry) atau `mount <mountpoint>` tanpa nyebut device-nya — sistem bakal auto-lookup opsinya dari `fstab`.
