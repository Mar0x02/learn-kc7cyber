# Daily Challenge - 2026-11-26

**Pertanyaan:** What is the name of the process state represented by D in ps, often associated with waiting for disk I/O?

**Jawaban:** Uninterruptible Sleep

**Penjelasan singkat:**
Pas lihat output `ps`, proses biasanya ada di state `S` (sleeping, nunggu sesuatu tapi bisa diganggu) atau `R` (running). Tapi ada satu state khusus, `D`, yang maknanya beda — proses ini lagi nunggu operasi I/O level rendah (misal baca/tulis ke disk atau request ke hardware) yang kernel **gak mau** dipotong di tengah jalan, karena kalau dipotong bisa bikin data korup atau device-nya jadi gak jelas kondisinya.

State `D` ini disebut **Uninterruptible Sleep** — proses "terkunci" sampai I/O-nya beneran selesai, gak bisa di-kill atau di-interrupt pakai sinyal biasa (bahkan `SIGKILL`) selama masih di state ini. Normalnya ini cuma sekejap, tapi kalau ada proses yang nyangkut lama di state `D`, itu biasanya tanda ada masalah serius (disk/storage error atau hang di hardware/driver).
