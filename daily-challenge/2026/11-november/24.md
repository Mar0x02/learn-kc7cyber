# Daily Challenge - 2026-11-24

**Pertanyaan:** What Linux system call takes a program pathname, an argument vector, and an environment vector to replace the current process image?

**Jawaban:** `execve()`

**Penjelasan singkat:**
Pola klasik di Linux kalau mau jalanin program baru dari dalam program yang udah jalan itu dua langkah: `fork()` dulu buat bikin copy process (child), baru child-nya itu "berubah wujud" jadi program lain. Bagian "berubah wujud" ini yang dilakuin `execve()`.

`execve()` nerima 3 argumen: path program yang mau dijalanin, argument vector (`argv[]`), dan environment vector (`envp[]`) — terus dia **ganti total isi process yang lagi jalan** (memory, code, data) dengan program baru itu, tanpa bikin process baru (PID-nya tetep sama, cuma "isi"-nya diganti).

Semua fungsi family `exec*()` di libc (`execl`, `execv`, `execvp`, dll) itu cuma wrapper yang ujung-ujungnya manggil `execve()` juga. Ini kenapa shell bisa jalanin command: dia `fork()` dulu, terus child-nya manggil `execve()` buat jadi program command itu.
