# Q12

**Pertanyaan:** Copy and paste the full URL that shows the operator resetting the password to Dwake's account.

**Konteks:**
Operator pakai info yang kebocor di verse (Washington, Fluffy) buat reset password Dwake. Query buat nemuin bukti aksi ini:
```kql
InboundNetworkEvents
| where timestamp between (datetime("2024-04-10T00:00:00") .. datetime("2024-04-11T00:00:00"))
| where url has_any("washington", "fluffy")
| where src_ip has "18.66.52.227"
```
![Reset password URL](./assets/q12-1-reset-password-url.png)

**Cara penyelesaian:** Copy full URL dari kolom `url` hasil query di atas.

**Jawaban:** `https://owl-records.com/account/security-questions?question_1=mother's+maiden+name&answer_1=Washington&question_2=first+pet's+name&answer_2=Fluffy`
